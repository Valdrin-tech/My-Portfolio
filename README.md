# Portfolio Website

A modern, minimalistic portfolio website for a Frontend Developer.

## Features
- Black background, white and gray text
- Large bold headings, clean sans-serif typography
- Smooth hover animations and transitions
- Responsive grid-based layout
- Sections: Hero, About, Skills, Projects, Experience, Contact

## Tech Stack
- React
- styled-components

## Getting Started

1. **Install dependencies:**
   ```sh
   npm install
   ```
2. **Start development server:**
   ```sh
   npm start
   ```
3. **Build for production:**
   ```sh
   npm run build
   ```

## Folder Structure
- `/src/components/` – Section components
- `/src/styles/` – Global styles

## Customization
- Update content in `/src/components/`
- Add or edit projects in `Projects.js`
- Update contact info in `Contact.js`

---

All code and styles are minimal, clean, and consistent with the design vision.
